# Barlow

Latin subsets of [Barlow](https://github.com/jpt/barlow) (400, 500, 600, 700), downloaded unmodified from Google Fonts. Copyright 2017 The Barlow Project Authors. Distributed under the SIL Open Font License 1.1; see `LICENSE.txt`.

Barlow is a slightly rounded grotesk drawn after California road signs and industrial lettering. It sets the interface: navigation, labels, inputs, buttons and small numbers. Loaded with `next/font/local`, served by this application and included in its offline asset cache.

Titles, large figures and Coach's replies use a serif instead, as New York does in the iPhone app: `ui-serif` shows New York in Safari, and other browsers get [Newsreader](https://github.com/productiontype/Newsreader) (Production Type, SIL OFL 1.1). Newsreader comes from `next/font/google`, which downloads it during the build and serves it from this application, so browsers never contact Google. Barlow Condensed, the previous display face, is retired.
