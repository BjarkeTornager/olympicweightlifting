# Barlow and Barlow Condensed

Latin subsets of [Barlow](https://github.com/jpt/barlow) (400, 500, 600, 700) and Barlow Condensed (500, 600, 700), downloaded unmodified from Google Fonts. Copyright 2017 The Barlow Project Authors. Distributed under the SIL Open Font License 1.1; see `LICENSE.txt`.

Barlow is a slightly rounded grotesk drawn after California road signs and industrial lettering, which suits plate markings and gym scoreboards better than a generic interface sans. Barlow Condensed sets titles, weights and reps.

Loaded with `next/font/local`, served by this application and included in its offline asset cache. No third-party font request is needed at runtime or during builds.
